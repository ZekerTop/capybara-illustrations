# Visual System

## 主体

默认主体是卡皮巴拉（水豚），不要画成泛化萌宠。

核心特征：

- 圆润偏大身体
- 小而圆的耳朵
- 钝钝的鼻口部
- 短小爪子
- 半垂眼或稳定平和的眼神
- 姿态慢悠悠、松弛、随遇而安

它可以站、坐、躺、推、抱、整理、漂浮、观察、递出下一步，但不要高速奔跑、夸张尖叫或变成表情包式大头角色。

## 情绪

默认情绪是稳定，不是无聊。可以用这些状态表达：

- 松弛
- 稳住
- 先放一放
- 慢慢来
- 下一步
- 不慌
- 好了，先这样
- 混乱被收起来

表情要微妙但可读：眼睛、嘴线、头部角度、爪子动作和身体重心都要服务观点。

## 颜色

默认 `soft-color`：

- 白底或透明白底
- 黑色线稿
- 柔和暖棕色主体
- 一个克制点缀色

建议点缀色：

- 绿色：完成、安定、下一步
- 蓝色：清晰、系统、流程
- 橙色：提醒、轻微混乱、待处理
- 淡黄色：温暖、缓冲、提示

当用户指定 `mono`、`黑白`、`不要颜色` 或 `白底黑线` 时，改为：

- 白底
- 黑色线稿
- 无主体填色
- 可保留短标注

## 文字

默认加入文字。文字要短、有趣、服务画面。

常用文字类型：

- 短标题
- punchline
- 物件标签
- 状态词
- 动作词
- 前后对比词

不要只写“少量标注”。要写出具体会放进图里的文字，例如：

```text
短标题：先放进盒子
标签：混乱输入 / 稳定水面 / 下一步
状态词：不慌 / 待处理 / 可以开始
```

## 避免

- 儿童贴纸感
- 网红表情包感
- 复杂商业插画
- 密集 PPT 信息图
- 只可爱但没有信息
- 只画物件，不标注状态
- 文字多到像说明书
- 颜色太花
